Como Publicar no Firebase Hosting

A Agenda SisInfra está pronta para ser publicada gratuitamente no Firebase Hosting & Cloud Firestore.

Passo 1: Criar o Projeto no Firebase

Acesse console.firebase.google.com, clique em Adicionar projeto e dê um nome (ex: agenda-sisinfra-ufpb).

Passo 2: Ativar Authentication e Cloud Firestore

Ative o Provedor de E-mail/senha no Authentication e inicie o Cloud Firestore na região de São Paulo (southamerica-east1).

Passo 3: Inserir as credenciais em js/firebase-config.js

Copie o objeto firebaseConfig gerado no console e cole no arquivo js/firebase-config.js.

Passo 4: Publicar via Terminal

No terminal desta pasta, execute:

firebase login
firebase use --add seu-projeto-id
firebase deploy
